# Learning

教程千千万, B站, 博客, 网络大学, 自创, 转载. 但无一例外都不是自己. 而且都没经过验证. 我也不知道其正确性. 而且还有一种可能因为系统.网络或者是作者个人的设置和配置, 根据教程做不出来实际的效果. 有些东西需要自己一点一点去实验. 而且有些东西压根就学不到. 比如说人家失败的过程. 人家以往的经历, 在做某实验的时候出现特殊情况. 除此之外每当遇到问题需要去往百度谷歌一遍一遍去搜, 是能找到答案, 但累不累呀? 可能今年看到的教程明年就消失不见了. 一是可能是真的忘记了网址. 二是平台跑路了网址失效. 

花时间去记录之前自己会的东西做成笔记或者是个人教程, 可以当做一个实验记录. 但是所有的文章最后要记录一下原始的教程地址. 即使跟原始教程一模一样. 但里边的步骤缺一不可. 截图代码文件之类的东西必须是用自己的.
